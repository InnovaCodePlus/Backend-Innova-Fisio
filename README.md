# Backend Innova Fisio

## Instalcion del proyecto
1. Abrir el proyecto en una terminal
2. Ejecutar el comando ``npm install``


## Correr el proyecto en desarrollo
1. Ejecutar el siguiente comando:
```bash
$   npm run start:dev
# o
$   nest start --watch
```

2. Abrir el navegador en la siguiente ruta: ``http://localhost:3000``
